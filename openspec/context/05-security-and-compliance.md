# Безопасность

Полные ограничения задаются следующими владельцами. Этот раздел помогает выбрать нужный контракт.

| Область | Нормативный источник |
|---|---|
| Оригиналы и безопасный запуск внешних процессов | [MEDIA-001/006](../specs/media-preparation/spec.md) |
| Сеть, докачка модели, фактическое устройство, изолированные процессы, облачное согласие и секреты поставщиков | [ASR-002…011](../specs/speech-recognition/spec.md) |
| Кеш без загрузки модели, форматная изоляция, разрешение перезаписи и резервные копии | [ART-001…009](../specs/recognition-artifacts/spec.md) |
| Локальная граница API, строгие схемы, отмена и очистка принадлежащих задаче каталогов | [WEB-001/002/008/010](../specs/local-web-workflow/spec.md) |
| Внешний текст, секреты, минимальная передача данных, проверяемая изоляция и полномочия агента | [SEC-CONTEXT-001…004](../specs/engineering-governance/spec.md) |
| Сохранность пользовательских данных при работе агента | [Общий профиль, пункты 9/12/13](../specs/engineering-governance/reference/python-common.md) |

Одобренных исключений из этих контрактов нет. Публичные поля API и параметры —
в [приложении интерфейсов](../specs/engineering-governance/reference/application-interface.md);
оно не расширяет разрешение на обработку или передачу данных.
