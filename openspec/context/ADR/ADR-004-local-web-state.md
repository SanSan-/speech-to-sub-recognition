# ADR-004: Локальный сервис с сохранённым состоянием задач

Статус: принято.

## Контекст

Долгая пакетная обработка должна сохранять наблюдаемое состояние при перезагрузке страницы или разрыве связи.
Перезапуск сервера не должен превращать незавершённую обработку в успешную.

## Решение

Ограничить веб-сервис локальной машиной. Сохранять задачи и события в SQLite независимо от состояния страницы.
Общий прикладной сервис выполняет распознавание; веб-слой управляет подготовкой, состоянием и доставкой событий.

## Альтернативы и последствия

Состояние только в браузере или памяти сервера отклонено: оно теряется вместе с интерфейсом или процессом.
Удалённый многопользовательский сервис отклонён для текущего продукта: ему нужна самостоятельная модель доступа
и владения данными.

Карточки, журнал и конечный результат восстанавливаются без нового запуска распознавания.
Это восстановление состояния, а не продолжение распознавания с середины файла.
Прерывание, повтор и очистка истории сохраняют самостоятельные условия допуска.

## Пересмотр

Принятый удалённый или многопользовательский режим, иной способ хранения либо продолжение обработки с середины файла.

Связанные требования: [локальный веб-процесс](../../specs/local-web-workflow/spec.md),
[публичные интерфейсы](../../specs/application-interface/spec.md).
