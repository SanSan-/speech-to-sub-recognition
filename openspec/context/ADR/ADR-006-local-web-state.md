# ADR-006: Локальное API и сохранённые состояния

## Status

Accepted.

## Context

Долгая пакетная задача должна переживать перезагрузку страницы, а незавершённая работа не должна выглядеть успешной.

## Decision

Веб-сервис ограничен локальной машиной и использует SQLite для постоянного состояния задач и событий.
Правила доступа, актуальности подготовки и восстановления заданы в [WEB-001/004/006/007](../../specs/local-web-workflow/spec.md).
Публичные поля и состояния перечислены в [приложении интерфейсов](../../specs/engineering-governance/reference/application-interface.md).

## Consequences

Можно восстановить карточки и журнал без повторного ASR; это не продолжение с середины файла.

## Alternatives considered

Состояние только в браузере или памяти сервера потеряло бы результат; удалённый сервис потребовал бы отдельной модели
доступа.

## Evidence

[Рабочий источник](../../../speech_to_sub/web/job_store.py), [связанный тест или свидетельство](../../../tests/test_web_app.py).
Наличие теста не означает успешный прогон.

## Review date

Появление принятого многопользовательского режима или продолжения ASR.
