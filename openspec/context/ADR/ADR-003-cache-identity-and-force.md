# ADR-003: Повторная обработка и защищённый жизненный цикл результата

Статус: принято.

## Контекст

Пользователю нужен другой формат без ненужного повторного распознавания, а явный пересчёт должен выполнить
тяжёлую обработку заново. Публикация нескольких артефактов может оборваться; удаление последней резервной копии
при неудачном восстановлении уничтожает путь возврата к прежнему результату.

## Решение

Отделить идентичность распознавания от идентичности форматной раскладки.
Общий сервис управляет повторным использованием Transcript, разрешением полного пересчёта и публикацией.
Форматы имеют изолированные результаты. Публикация согласует набор артефактов и сохраняет возможность восстановления
при отказе; невосстановленная резервная копия не становится мусором для автоматической очистки.

## Альтернативы и последствия

Один отпечаток для всего результата отклонён: смена формата повторяла бы тяжёлое распознавание.
Лёгкий пересчёт по явному полному force отклонён: он не выполняет выбранное пользователем действие.
Прямая перезапись и безусловная очистка резервных файлов отклонены: частичный отказ может уничтожить прежние данные.

Другой формат может использовать сохранённое распознавание. Явный полный пересчёт не затрагивает соседний формат.
Существующий неподтверждённый результат требует разрешения на замену. Публикация нескольких файлов не обещает
неограниченного отката при системном отказе; сохраняется материал для восстановления.

## Пересмотр

Изменение смысла полного пересчёта, границы совместимости результатов или модели публикации.
