# Контекст продукта

Локальная утилита выполняет автоматическое распознавание речи (ASR) для выбранной аудиодорожки файла или пакета записей
и создаёт SRT, ASS либо WebVTT и диагностический JSON. Независимый выравниватель (aligner) уточняет время слов,
не заменяя распознанный текст. Пользователь работает через командный или локальный веб-интерфейс;
локальное распознавание — основной режим, облачная отправка требует отдельного согласия.

Ключевые сценарии: пакет с частично повреждёнными медиа; явный выбор дорожки; повтор по кешу; формирование
отсутствующего формата из сохранённого распознавания; полный пересчёт с force; восстановление веб-задачи после разрыва
соединения.

Инварианты: оригиналы неизменны; выбранный формат не повреждает соседний; движки возвращают общий текст и метки; явный
force повторяет тяжёлую обработку; ошибки отдельного файла изолированы; секреты не становятся данными задачи.

Ограничения: ручного RU/EN эталона качества ещё нет; скорость и структурная корректность не доказывают точность текста.
Transformers держит полное несжатое аудио. Нет продолжения с середины файла, диаризации, редактора, встраивания в
контейнер, многопользовательского сервиса или multi-GPU. Синхронный сетевой вызов отменяется только до/после возврата.
Linux/macOS/WSL не прошли полный подтверждающий цикл.

Пакет имеет ограничение Requires-Dist=0: зависимости устанавливаются по requirements.txt; внешний выпуск требует
отдельного контракта. [Текущая работа](../changes/README.md).
