# Архитектура

Командный и локальный веб-интерфейсы обращаются к одному прикладному сервису.
Общий результат распознавания — Transcript — отделяет содержание и временные якоря от раскладки и форматов.

Схема обработки и границ ответственности:

```mermaid
flowchart LR
    CLI[Командный интерфейс] --> Service[Прикладной сервис]
    Web[Локальный веб-интерфейс] --> Service
    Web <--> Jobs[Задачи и события · SQLite]
    Service --> Media[Подготовка аудио]
    Media --> ASR[Адаптер распознавания]
    ASR --> Worker[Изолированная модельная среда]
    ASR --> Cloud[Внешний поставщик · явное согласие]
    ASR --> Align[Выравнивание]
    Align --> Transcript[Общий результат]
    Service <--> Cache[Сохранённое распознавание]
    Cache --> Transcript
    Transcript --> Layout[Текстовая и временная раскладка]
    Layout --> Format[SRT / ASS / WebVTT]
    Format --> Publish[Публикация результатов]
```

| Компонент                  | Ответственность и граница                                                                   |
|----------------------------|---------------------------------------------------------------------------------------------|
| Интерфейсы                 | Выбор входов и настроек, наблюдение результата; не создают отдельный конвейер распознавания |
| Прикладной сервис          | Порядок обработки, повторное использование результата и согласованная публикация            |
| Подготовка аудио           | Чтение исходных медиа, выбор дорожки и рабочее аудио; оригиналы остаются вне записи         |
| Адаптеры и модельные среды | Распознавание и выравнивание через общий результат; несовместимые зависимости изолированы   |
| Раскладка и форматы        | Содержание Transcript и якоря преобразуются в субтитры без изменения исходного результата   |
| Локальный веб-сервис       | Подготовка, состояние задачи и события; постоянное состояние отдельно от страницы           |
| Кеш и публикация           | Совместимость повторного результата и сохранность форматных артефактов                      |
| Внешний поставщик          | Отдельная граница передачи аудио, разрешённая выбранным облачным режимом                    |

Схема задаёт потоки и ответственность. Конкретные условия пропуска этапов, доступа и отказа находятся у владельцев ниже.
