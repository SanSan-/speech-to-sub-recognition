# Начало работы

1. Прочитай [контекст продукта](01-product-context.md), [инженерные ограничения](../specs/engineering-constraints/spec.md), [команды](../../README.md#подготовка-сред), [безопасность](05-security-and-compliance.md) и [антипаттерны](07-anti-patterns.md).
2. По вопросу выбери [словарь](02-domain-glossary.md), [архитектуру](03-architecture.md), [инженерные ограничения](04-engineering-standards.md), [качество](06-testing-and-quality.md), [примеры](examples/README.md) и [принятые решения](ADR/README.md).
3. Текущая работа находится в [openspec/changes](../changes/README.md); владельцы предметных требований — в [карте архитектуры](03-architecture.md#владельцы-контрактов), публичные параметры — в [спецификации интерфейсов](../specs/application-interface/spec.md).
4. Известные разрывы реализации перечислены в [нерешённых проблемах](failure-log.md); факт реализации и принятое требование различаются.
