# Известные проблемы

## Новое облачное согласие в CLI

Причина: отсутствующий CLI-флаг имел значение `None`; слияние сохраняло прежнее согласие из окружения или `.env`.
Исправление [ASR-008](../specs/speech-recognition/spec.md#requirement-asr-008-явный-облачный-режим): отсутствующий флаг
имеет значение `False`, поэтому каждый вызов заново определяет разрешение. Общий загрузчик окружения не изменён.
Связь с реализацией и регрессионным сценарием — в [карте примеров](examples/README.md#граница-проверки-облачного-согласия).

## Ограничение чтения JSON-кеша

Причина: общий загрузчик полностью читал и разбирал соседний JSON до проверки его совместимости.
По [ART-010](../specs/recognition-artifacts/spec.md#requirement-art-010-ограниченное-чтение-json-кеша)
чтение теперь ограничено 64 МиБ до декодирования и разбора; отдельная причина отказа позволяет
сервису сохранить полный или неполный набор результатов. Поздний отказ перед добавлением FLAC
останавливает публикацию; явный force сохраняет полный обход кеша.

## Завершение ffprobe по тайм-ауту

Причина: после тайм-аута внешнего `taskkill` потомок мог удерживать каналы вывода;
закрытие канала ожидало фонового читателя и задерживало возврат ошибки.
Windows-процесс теперь присоединяется к Job Object до начала исполнения. Закрытие Job Object
завершает его потомков даже после выхода родителя. В [регрессиях](../../tests/test_ffmpeg.py)
сохранён предел менее 2 с; они проверяют отказ назначения, живой потомок завершившегося родителя и обычный запуск.

## Поздняя проверка Python изолированного профиля

Причина разрыва [IFACE-001](../specs/application-interface/spec.md#requirement-iface-001-разрешение-и-проверка-настроек):
проверка Python находилась в подготовке движка или выравнивателя после нормализации аудио;
общий вход обработки заранее проверял только FFmpeg/ffprobe.
Общий вход теперь проверяет Python выбранных изолированных профилей до проверки потоков, нормализации
и обращения к кешу. Разрешение путей общее с адаптерами, поэтому приоритеты настроек не расходятся.
Отказ сохраняет прежние результаты, включая запуск с force; невыбранные профили не требуют интерпретатора.
Связь с реализацией и регрессионными сценариями — в [карте проверки](examples/README.md#связи-контрактов-с-реализацией).
