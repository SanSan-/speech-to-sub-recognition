# Ошибки контекста
Для подтверждённого сбоя контекста фиксируются дата, задача, нарушенное условие, источник, необходимое уточнение и реально обновлённое правило либо причина отсутствия изменения. Непроверенная гипотеза не записывается как произошедший инцидент.
