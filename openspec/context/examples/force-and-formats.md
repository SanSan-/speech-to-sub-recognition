# force, форматы и сохранение данных

Требования: [ART-001–004](../../specs/recognition-artifacts/spec.md). Рабочий
вход: [process_paths](../../../speech_to_sub/service.py).
Проверка: [test_format_switch_reuses_recognition_and_keeps_artifacts_isolated](../../../tests/test_service.py).

| Условие и действие                                                                         | Наблюдаемый результат существующего теста                                     |
|--------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------|
| Временный источник, language=ru, keep_audio=true; по очереди SRT, ASS, VTT, force не задан | Один вызов FakeBackend; три форматных результата; srt_output=null для ASS/VTT |
| Удалён только созданный тестом VTT, повтор VTT без force                                   | VTT восстановлен, число вызовов backend остаётся 1                            |
| Затем ASS с force=true                                                                     | Число вызовов backend становится 2; SRT побайтно прежний                      |

Видны форматные sidecar/FLAC и синтаксическая читаемость ASS/VTT. Источник, аудио и backend в тесте имитируются: это не
проверка качества реальной модели и не платный вызов.

Для отказа
публикации: [test_artifact_commit_keeps_unrestored_backup_after_double_failure](../../../tests/test_service.py)
проверяет сохранённую резервную копию после ошибки публикации и восстановления. Нельзя заменять этот контракт проверкой
только исключения.

Приведённые сценарии задают ожидаемое поведение; результат выполнения фиксируется отдельным прогоном.
