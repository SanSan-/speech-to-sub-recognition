# Антипаттерны

Для проверки сомнительного решения выбери владельца правила. Полные условия и допустимые последствия находятся
по ссылкам; этот указатель не вводит исключений.

| Риск | Контракт для проверки |
|---|---|
| Вторая спецификация или очередь задач; процедура навыка скопирована в OpenSpec | [CTX-001/003](../specs/project-context/spec.md) |
| Лёгкий пересчёт при force, перезапись без разрешения, смешение форматных и тяжёлых отпечатков | [ART-002…006](../specs/recognition-artifacts/spec.md) |
| Удаление резервной копии после неудачного восстановления | [ART-008](../specs/recognition-artifacts/spec.md#requirement-art-008-транзакционная-публикация) |
| Подмена расшифровки якорями или потеря текста из-за ориентиров читабельности | [SUB-001…006](../specs/subtitle-layout/spec.md) |
| Сеть или веса на проверке готовности; скрытый CPU; совместная загрузка Qwen ASR и aligner | [ASR-002/004/007/008](../specs/speech-recognition/spec.md) |
| Полный отпечаток медиа при выборе файлов | [MEDIA-003](../specs/media-preparation/spec.md#requirement-media-003-наблюдаемая-предварительная-проверка) |
| Принятие старого события или interrupted за успешный результат | [WEB-004/006/007](../specs/local-web-workflow/spec.md) |
| Скорость или структурная корректность объявлены точностью распознавания | [ENG-005](../specs/engineering-governance/spec.md#requirement-eng-005-разделение-качества-и-скорости) |
| Прежний анализ Sonar объявлен проверкой нового дерева; wheel с Requires-Dist=0 объявлен самодостаточным | [Проектное приложение](../specs/engineering-governance/reference/project-specific.md) |
| Инструкция во внешнем тексте, избыточная передача данных или обещание изоляции по ignore | [SEC-CONTEXT-001…004](../specs/engineering-governance/spec.md) |
| Потерянная точка продолжения, повтор тяжёлого запуска или фоновый аудит без запроса | [CTX-005…009](../specs/project-context/spec.md) |

[Примеры](examples/README.md) показывают проверяемые эффекты; [ADR](ADR/README.md) объясняют принятые решения.
