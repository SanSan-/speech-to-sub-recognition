# Словарь

| Термин            | Значение в проекте                                                                 |
|-------------------|------------------------------------------------------------------------------------|
| Transcript        | Нормализованные текст, сегменты и слова ASR; исходные данные для всех форматов     |
| ASR               | Автоматическое распознавание речи; не перевод и не раскладка субтитров             |
| Aligner           | Независимый адаптер временного выравнивания распознанного текста                   |
| Словный якорь     | Временная опора слова; не альтернативный источник текста                           |
| MediaProbe        | Подтверждённые сведения о контейнере и его аудиопотоках                            |
| ordinal           | Нулевой порядковый номер среди аудиопотоков, не container index                    |
| Sidecar           | Сопроводительный JSON результата с источником, Transcript и отпечатками            |
| Тяжёлый отпечаток | Идентичность распознавания, дорожки, модели и фактической среды                    |
| Лёгкий отпечаток  | Формат, версия формирователя и настройки раскладки                                 |
| force             | Полный обход кешей результатов с новым ASR и разрешённой заменой вычисленных целей |
| CPS               | Число отображаемых символов в секунду; ориентир планирования и диагностики         |
| cached / skipped  | Подтверждённое совпадение / сохранение существующего неподтверждённого результата  |
| interrupted       | Сохранённая незавершённая задача после перезапуска, не успешное завершение         |
| WER / CER         | Ошибка по словам / символам относительно ручной эталонной расшифровки              |
